# TCP Client-Server Application

A network application implemented using POSIX sockets.

## Features

* TCP client-server communication
* Connection establishment and termination
* Data transmission over the network
* Error handling and resource cleanup

## Concepts

* Socket Programming
* TCP/IP Networking
* Client-Server Architecture
* Network Byte Order

## Technologies

* C
* Linux
* POSIX Sockets

## Learning Outcomes

This project demonstrates the implementation of network applications using low-level socket APIs and provides practical experience with communication protocols and network programming.
