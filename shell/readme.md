# Unix Shell

A Unix-like shell implemented in C.

## Features

* Command execution
* Foreground and background processes
* Process creation using `fork`
* Program execution using `exec`
* Signal handling
* Pipe support
* Command parsing

## Concepts

* Process Management
* Signals
* Inter-Process Communication
* Linux System Calls

## Technologies

* C
* Linux
* POSIX APIs

## Learning Outcomes

This project provides hands-on experience with process creation, process control, command execution, and communication between processes in a Linux environment.
