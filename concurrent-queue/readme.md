# Concurrent Queue

Thread-safe queue implementation supporting concurrent access by multiple threads.

## Features

- FIFO queue operations
- Thread synchronization
- Mutual exclusion
- Safe concurrent access

## Concepts

- Multithreading
- Synchronization
- Producer-Consumer Patterns
- Concurrent Data Structures

## Technologies

- C
- POSIX Threads

## Learning Outcomes

Gained experience designing and implementing synchronization mechanisms and concurrent data structures in a multithreaded environment.
